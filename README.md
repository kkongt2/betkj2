# 복연승 · 같은 금액, 누적 수익

`kkongt2/betkj2` 저장소에서 독립적으로 운영하는 복연승 전용 정적 웹 앱입니다.

페이지: https://kkongt2.github.io/betkj2/ 자동 사전예측 기록, 연승 추천, 적중률/가치 기준 전환은 포함하지 않습니다.

## 현재 결과

공식 보고서 1,620개, 경주 이력 12,903건 중 복연승 확정 배당을 확인한 12,714경주를 확보했습니다. 2021년은 과거 이력 생성에 사용하고, 이후 11,092경주의 552,415개 조합으로 모델을 구성했습니다.

| 구간 | 역할 | 경주 수 |
|---|---|---:|
| 2022–2024 | 확률 및 적중 시 배당 모델 학습 | 7,031 |
| 2025.01–03 | 확률·배당 보정 | 586 |
| 2025.04–12 | 총 순손익으로 조건 선택 | 1,806 |
| 2026.01–09.10 | 선택 조건 고정 후 평가 | 1,669 |

배당 모델 2종 × 기대수익률 하한 8종 × 경주당 최대 조합 수 3종, 총 48개 조건을 비교했습니다. 선택 구간에서 가장 높은 총 순손익을 보인 연구 조건은 **Gamma 배당 모델, 기대수익률 10% 이상, 경주당 상위 1조합**입니다. ROI가 아니라 같은 단위 금액을 베팅한 **총 순손익**으로 선택했습니다.

| 결과 | 조건 선택 구간 | 분리 평가 구간 |
|---|---:|---:|
| 조합 수 | 447 | 426 |
| 고정 단위금액 | 10,000원 | 10,000원 |
| 총 베팅액 | 4,470,000원 | 4,260,000원 |
| 세전 순손익 | -489,000원 | +261,000원 |
| 수익률 | -10.94% | +6.13% |

평가 구간 적중률 15.73%, 적중 시 평균 배당 6.75배, 일별 최대 낙폭 561,000원. 수익률의 날짜 단위 재표집 95% 신뢰구간은 **-27.11% ~ +40.24%**입니다. 최고 수익일을 제외하면 **-126,000원**입니다.

**흑자 검증 통과 실패. 현재 실행 정책은 베팅 추천 보류입니다.** 선택 구간에서 손실이 났으므로 아무것도 베팅하지 않는 선택(손익 0)이 더 좋습니다. 화면의 조합은 비교를 위한 연구 후보이며, 장기 흑자 전략으로 승인된 추천이 아닙니다. 2026년 결과를 보고 추가 조정하지 않았습니다.

## 하나의 추천 기준

`추정 기대수익률 = 추정 적중확률 × 적중 시 예상 환급배당 − 1`

- 적중확률: 과거 경주 이력으로 학습한 이진 분류 모델과 별도 보정.
- 예상 배당: 과거 적중 조합의 확정 배당으로 학습한 조건부 평균 배당 모델. 실시간 배당이나 미래의 실제 배당을 입력하지 않습니다.
- 경주당 허용 조합 수까지 기대수익 순으로 선택하고, 각 조합에 같은 10,000원을 적용합니다. 복리·추격 증액을 사용하지 않습니다.
- 공식 배당으로 환급액을 계산한 뒤 베팅 원금을 차감합니다. 공식 배당에 반영된 공제율을 다시 빼지 않습니다. 개인별 적중금 세금·입장 비용은 반영하지 않은 **세전** 손익입니다.
- `1 / 추정 적중확률`은 세전 손익분기 배당입니다. 사용자의 실제 적용 배당과 모델 추정 배당은 다를 수 있습니다.

승인 조건은 선택 구간 흑자, 분리 평가 200조합·60경기일 이상, 수익률 95% 신뢰구간 하한 0 초과, 최고 수익일 제외 후에도 흑자입니다. 기준에 실패하면 연구 후보만 보여줍니다. 48개 후보 밖의 전역 최적값이나 미래 흑자를 입증한 것은 아닙니다.

## 배포와 갱신

이 저장소의 `main` 브랜치에서 `Update and publish QPL page` 작업으로 GitHub Pages를 배포합니다. **Settings → Pages → Source**는 **GitHub Actions**를 사용합니다.

워크플로는 자신의 저장소에만 데이터 갱신 내용을 저장하고 Pages를 직접 배포합니다. 기존 `timeline` URL이나 브랜치를 참조하지 않습니다. 목~일 한국시간 09–21시에는 약 20분마다, 월~수에는 09:05에 실행하도록 설정했습니다. GitHub 예약 실행은 지연될 수 있습니다. 수집 실패 시 마지막 게시 파일을 유지하며, 화면은 데이터가 30분보다 오래되면 갱신 필요를 표시합니다.

기존 자동 사전예측 저장·정산 작업은 복사하지 않았습니다. `backtest-bets.json`은 모델 검증용 과거 계산 자료로, 사용자의 실제 베팅이나 실제 사전예측 기록이 아닙니다.

```sh

```

브라우저에서 `http://localhost:8000`을 엽니다.

```sh

```

Python–JavaScript 수치 일치, 말 순서 변경, 결측·오래된 이력, 출전 두수 변경, 실제 배당과 고정금액 손익 일치, 승인 조건, 원클릭 라운드 선택, 지역별 경주일, 과거 확정 결과 표시를 검사합니다.

재현:

```sh
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python scripts/train_profit.py
```

학습 데이터와 배당 라벨은 저장소에 포함되어 있습니다. `Reproduce frozen profit experiment` 작업도 같은 실험을 재현하지만 결과를 자동 배포하거나 모델을 교체하지 않습니다. 새로운 가설을 검증할 때는 이 평가 결과를 본 사실을 기록하고, 다른 미사용 기간으로 평가해야 합니다.

## 데이터와 한계

- 한국마사회 공식 일별 결과 보고서: `training/manifest.json`에 원본 URL과 해시.
- 검증된 조합별 확정 배당: `training/payouts.json.gz`에 보고서 URL·원문 해시.
- 배당 미확인·해석 제외 189경주: `training/payout-quality.json`. 누락 배당은 0배나 미적중으로 대체하지 않습니다.
- 날짜마다 같은 날 결과를 입력하기 전 모든 경주의 특징을 생성합니다. 개별 말 현재 경주의 착순·구간 기록·배당은 사전 특징에 포함하지 않습니다.
- 역사적 보고서에 영구 말 ID가 없어 지역·이름·출생연도 추정·성별을 조합합니다. 이름 변경 등으로 이력이 분리될 수 있습니다.
- 2026년 구간은 이번 수익 실험에서만 선택과 분리했습니다. 이전 적중률 연구에서 사용된 날짜이므로 완전히 새로운 독립 시험이 아닙니다.
- 최대 낙폭은 경기일 종료 누적 손익 기준이며 장중 낙폭을 뜻하지 않습니다. 같은 경주의 여러 조합은 서로 독립적이지 않습니다.
- 현재 모델은 2024년까지 학습한 고정 모델입니다. 사전 이력 입력은 갱신하지만 새 결과로 자동 재학습하지 않습니다.

학습·조건·평가 근거는 `data/experiment.json`, `data/frozen-policy.json`, `data/backtest.json`에 남아 있습니다.

## 경주 조회 범위

한국시간 기준 이번 주와 지난 두 주(지지난주 월요일 이후)의 실제 경주일을 표시합니다. 지난 경주는 공식 보관 자료와 결과를 사용하고, 예측은 현재 보관된 이력에서 해당 경주일 이전 자료만 골라 재계산합니다. 최신 경주 수집 때도 이 범위의 기존 경주를 유지합니다.


## 가중치 실험실

9개 항목의 사용자 가중치(0–100)로 동일 경주 내 최소·최대 정규화 점수를 가중 평균해 후보를 정렬합니다. 모든 가중치 0이면 무베팅입니다. 모델 확률·예상 배당은 고정하며 점수는 확률이 아닙니다. 기존 트리 모델의 계수를 변경하거나 재학습하는 기능은 아닙니다.

2025.04.01–2026.09.10의 **전체 조합**을 다시 선택해 매 조합 10,000원으로 정산합니다. 확정 배당은 정산에만 사용합니다. 기본값(예상수익 100, 나머지 0, EV 하한 10%, 경주당 1개)은 2026 평가의 426회 / +261,000원과 선택 마번까지 재현합니다. 학습과 브라우저 모두 pair features를 float32로 맞춰 분기 경계 차이를 제거했습니다.

조절 즉시 현재 후보가 바뀌며, 전체 손익·월별·지역별 표는 Web Worker에서 150ms 입력 지연 후 계산합니다. 최초 gzip 자료 다운로드 뒤에는 서버 요청 없이 기기에서 계산합니다. 설정은 localStorage에 저장하고 기본값 복원과 정산 내역 CSV를 제공합니다. 결과를 보며 조절한 기간은 더 이상 독립 검증이 아니므로 기존 모델의 고정 평가를 별도로 유지합니다.

재생성: `python scripts/export_tuning.py` → `node tests/tuning.cjs`. 데이터·모델·생성 코드 해시가 다르면 게시 워크플로가 자료를 다시 만듭니다.


## 이름별 조합 저장과 잠금

현재 가중치·선택 조건·평가 범위를 이름별로 최대 30개 저장하고 불러올 수 있습니다. 저장 위치는 현재 브라우저이며 JSON 백업·가져오기를 지원합니다. 같은 이름은 자동으로 덮어쓰지 않습니다. 잠금은 가중치, EV 하한, 최대 선택 수, 평가 범위, 기본값 복원, 조합 불러오기를 차단하고 새로고침 후에도 유지합니다. 저장·백업 및 경주 조회는 가능합니다.

첨부 원본 80/35/80/0/60/5/20/30/75의 2026 손익 +1,027,000원을 재현했습니다. `scripts/search_weights.py`는 고정 시드 20260913, EV 하한 10%, 경주당 1조합, 10,000원 베팅을 유지하며 14,340개 가중치를 사후 탐색합니다. `scripts/report_weights.cjs`는 실제 브라우저 계산기로 후보를 재검증하며 월·지역·낙폭·상위 환급 제외·10% 환급 감소 결과를 보고합니다. 결과는 `data/weight-recommendations.json`과 `data/weight-search-summary.json`에 있습니다. 재현하려면 기존 requirements 설치 후 `OPENBLAS_NUM_THREADS=2 python scripts/search_weights.py` 및 `node scripts/report_weights.cjs`를 실행합니다. 전체 탐색표는 재현 시 생성하며 git에는 요약을 보관합니다.

2025/2026 결과를 모두 확인한 뒤 탐색했으므로 독립 검증이 아니며 최고 수익·합산 수익·첨부 대비 개선의 장단점을 나눠 표시합니다. 기본 모델을 교체하거나 사용자 설정을 자동 적용하지 않습니다.


정액 베팅은 조합당 10,000원입니다. 선택 조합·가중치·적중률·ROI는 그대로이며 세전 손익, 환급액, 투입금, 낙폭과 CSV 정산액만 기존 1,000원 기준의 10배로 환산합니다. 금액 증가는 모델 성능 개선을 의미하지 않습니다.
