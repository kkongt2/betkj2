강건 전략 · 순차 검증

10,000원 정액

과거 오차를 반영한 기대수익으로 고르고, 손실 한도를 통과한 설정을 다음 달에 적용합니다.

월별 적용 설정을 계산하고 있습니다.

위험 한도 조절 · 계산 방법

기본 한도: 최대낙폭 30만 원, 주간 CVaR 10만 원. 초기 연구 설정이며 최적 한도가 아닙니다. 잠금은 가중치 실험실의 버튼으로 함께 설정합니다.

① 최소 6개월의 이전 자료로 월별 실제 환급/예상 환급 비율을 계산합니다. 지역·예상수익 구간별 비율을 표본 경주 수/(경주 수+50)만큼 반영하고 전체 비율로 보정합니다. 월별 비율의 하위 20% 분위수를 1 이하로 제한해 원래 예상 환급에 곱합니다. 이는 보수적 시나리오이며 확률의 신뢰구간이나 실제 손익 하한은 아닙니다.

② 보정 기간 뒤 3개월에서 사전에 정한 가중치 27개 × 보수적 하한 0·5·10·20% = 108개를 비교합니다. 양의 손익, 20조합·10개 경주 주간 이상, 두 위험 한도를 통과한 설정 중 총 세전 손익 최대를 선택합니다. 경주당 1조합이며 통과 설정이 없으면 다음 달 선택을 보류합니다.

③ 다음 1개월에 설정과 보정값을 고정합니다. 이를 매달 반복하고 다음 달 평가 결과만 이어 붙입니다. CVaR는 손실이 큰 20% 주간의 평균이며 경주가 있었지만 베팅하지 않은 주간도 포함합니다. 평가 표본이 적으면 극단손실 추정이 불안정합니다. 이 기능은 기초 예측모델 자체를 매달 재학습하지 않습니다.

워크포워드 세전 손익자료 준비 중

과거 전체 조합 자료를 준비합니다.

가중치 실험실

슬라이더를 움직이면 이 실험실의 과거 누적손익이 바뀝니다. 경주 후보 기준을 ‘직접 조절한 가중치’로 선택하면 아래 후보 순위에도 반영됩니다. 각 조합에 10,000원씩 고정 베팅합니다.

저장 파일 백업·복원

최대 30개. 가중치·선택 조건·평가 범위를 이 브라우저에 저장합니다. 브라우저 데이터를 지우거나 기기를 바꿀 때는 백업 파일을 사용해 주세요.

첨부 조합과 탐색 후보 비교

위 목록에서 비교 조합을 선택하고 불러오면 직접 확인할 수 있습니다. 자동으로 적용하지 않습니다.

조정 후 누적손익자료 준비 중

각 그래프는 다른 설정·평가 기간·지역을 고정하고 해당 항목만 0~100%까지 1%씩 바꾼 과거 누적손익입니다. 그래프를 누르면 값이 적용됩니다. 가중치 그래프의 %는 슬라이더 값이며, 합으로 환산한 비중과는 다릅니다. 강건 전략의 자동 가중치는 바뀌지 않습니다.

선택 조건·평가 범위

모델을 불러온 뒤 시뮬레이션 자료를 준비합니다.

월별·지역별 손익
가중치 계산법과 해석

각 항목은 같은 경주의 모든 조합 중 최솟값 0, 최댓값 100으로 환산(0.01점 단위)하고, 가중치의 합으로 나눈 가중 평균으로 순위를 정합니다. 항목 값이 모두 같으면 50점입니다. 모든 가중치가 0이면 베팅하지 않습니다.

모델 기대수익률 하한을 통과한 조합에서 사용자 점수 순으로 선택합니다. 동점은 모델 기대수익률과 마번 순으로 정합니다. 기본값은 예상수익 100·나머지 0, 하한 10%, 경주당 1조합이며 기존 고정 모델의 선택을 재현합니다. 사용자 점수는 확률이 아니며 모델을 재학습하는 기능도 아닙니다.

과거 실제 배당은 선택이 끝난 뒤 정산에만 사용합니다. 과거 결과를 보며 가중치를 고르면 해당 기간의 결과에 맞춰질 수 있으므로, 조정 후 흑자는 새로운 독립 검증 성과가 아닙니다. 기존 모델의 검증 결과는 아래에 별도로 유지합니다. 세전 손익이며 개인별 세금·입장 비용은 제외합니다.

가중치는 이 브라우저에 자동 저장됩니다. 후보 조회 날짜·지역과 손익 평가 범위는 별도입니다. 최초 자료 다운로드 후 계산은 기기에서 실행됩니다.
