가중치 실험실

슬라이더를 움직이면 아래 경주의 후보 순위와 과거 누적손익이 함께 바뀝니다. 각 조합에 1,000원씩 고정 베팅합니다.

선택 조건·평가 범위

모델을 불러온 뒤 시뮬레이션 자료를 준비합니다.

월별·지역별 손익
가중치 계산법과 해석

각 항목은 같은 경주의 모든 조합 중 최솟값 0, 최댓값 100으로 환산(0.01점 단위)하고, 가중치의 합으로 나눈 가중 평균으로 순위를 정합니다. 항목 값이 모두 같으면 50점입니다. 모든 가중치가 0이면 베팅하지 않습니다.

모델 기대수익률 하한을 통과한 조합에서 사용자 점수 순으로 선택합니다. 동점은 모델 기대수익률과 마번 순으로 정합니다. 기본값은 예상수익 100·나머지 0, 하한 10%, 경주당 1조합이며 기존 고정 모델의 선택을 재현합니다. 사용자 점수는 확률이 아니며 모델을 재학습하는 기능도 아닙니다.

과거 실제 배당은 선택이 끝난 뒤 정산에만 사용합니다. 과거 결과를 보며 가중치를 고르면 해당 기간의 결과에 맞춰질 수 있으므로, 조정 후 흑자는 새로운 독립 검증 성과가 아닙니다. 기존 모델의 검증 결과는 아래에 별도로 유지합니다. 세전 손익이며 개인별 세금·입장 비용은 제외합니다.

가중치는 이 브라우저에 자동 저장됩니다. 후보 조회 날짜·지역과 손익 평가 범위는 별도입니다. 최초 자료 다운로드 후 계산은 기기에서 실행됩니다.
